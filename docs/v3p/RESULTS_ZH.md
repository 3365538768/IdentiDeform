# V3p：V2 前馈先验管线在 V3 数据上的复现与对比

生成时间 2026-11-15T18:14:24Z；源数据 `docs/v3p/RESULTS.json`（明细 `RESULTS_raw.json`）。

## 结论（2000 条训练样本，V2 原管线原超参）

- **V3 上前馈先验明显变弱。** 9 头集成 test：z-MAE 0.775（V2 0.646），类别准确率 0.55（V2 0.74），族内 Spearman r(E/ρ) 0.42（V2 0.65），r(σ/ρ) 0.47（V2 0.79）。单个 C 头 test z-MAE 0.799（V2 0.676）。

- **按 decade 比较（跨数据集公平口径）：** V3 test E/ρ 误差 0.464 dec（V2 0.413），σ/ρ 0.279 dec（V2 0.530）。绝对误差看似相近甚至更小，是因为 V3 的范围窄：常数基线本身就只有 0.555 / 0.322 dec（V2 0.866 / 1.054）。相对常数基线，V3 先验只把 E/ρ 误差降低 17%、σ/ρ 降低 13%（V2 为 52% / 50%）。

- 仍明显优于外观基线：首帧 DINOv3 ≈ 常数（V3 test z-MAE 0.858 vs 常数 0.858），视频先验也优于特权的 GT 类均值（0.834）。B/C/D 之间仍无可分辨差异（与 V2 一致，场监督/反馈无收益）。

- 每种动作都退化（docs/v3p/PER_ACTION_VAL.json，val 集成）：族准确率从 0.60–0.84 降到 0.48–0.60，plasticine 最难（val 仅 26/94 判对）；shear 下 r(σ/ρ) 几乎为 0。drop 不经过夹板也退化，说明不只是接触方式的问题：可能与重力减小（drop 重力 2）、族间参数范围重叠（GT 类均值仅比常数好 0.030 z）、以及物体在画面中更小有关（抽查 val 前 24 个样本，物体像素占比约为 V2 的 1/3）。这些是推测，未做受控验证。

## 与 V2 的差异 / 偏离

- Data: V3 = contact through external rigid plates/grippers; gravity 2 (press/tap30hold/drop) else 0; narrower log10 ranges (E/rho jelly 3.5-6, plasticine 3.5-5.5, metal 4.5-6; sigma_y/rho 3.2-4.5); per-sample censoring sigma/rho > 0.5 E/rho (any law); screened objects v3_split (57/10/10).

- Train set: 2000 V3 samples (V2: 1955); val 283 / test 300 (V2: 283 / 300).

- Standardization from V3 train: std(ln E/rho) = 0.666 decades (V2 1.068), std(ln sigma_y/rho) = 0.369 decades (V2 1.166); 1098/2000 train samples carry a sigma label (V2 1264/1955). z-units therefore differ; decade errors are the cross-dataset comparison.

- Class information is much weaker in V3: privileged GT-class mean reaches z-MAE 0.827 vs constant 0.857 (V2: 0.786 vs 0.858), because the per-law ranges overlap.

- 协议：Same V-JEPA 2 ViT-L frozen 32-step features (64 frames, tubelet 2, 3 views, 224 px), same 2-layer transformer head and hyper-parameters (configs/v2main/* with only data paths/output changed), same loss weights (smooth-l1 + 0.05 NLL + 0.1 class CE; C/D field weight 0.1, 2 field-warmup epochs, D feedback=fields), seeds 17/29/43, best-val-epoch selection (best_material.pt), early stop patience 5 / min 8 joint epochs, test evaluated once.

- 偏离：Feature cache built incrementally into one shared directory (scripts/v3p/cache_v3.py, same encoder code path as scripts/prepare_vjepa_cache.py); per-manifest index.json files point into it. No change to features.

- 偏离：IO fix during training (14:31-14:45 UTC): 8 of 9 runs were paused at an epoch boundary (control.json, built-in mechanism) and resumed from last.pt with scripts/v3p/train_job.py --preload (features read once into RAM; identical math/sampling; verified on a smoke run: val MAE identical to 1e-4). C_seed29 was not paused.

- 偏离：First-frame DINOv3 baseline uses a first-frame-only DINOv3 cache (frames 1..15 stored as a stride-0 copy of frame 0; they are masked by static_first_frame anyway), not the full 16-frame cache.

- 偏离：Within-class correlation: V2 tables use Pearson; both Pearson and Spearman are reported here.

- 偏离：C/D were trainable: V3 packs contain the same stress/flow/force_mask fields as V2 (contact channel is empty in both V2 and V3).

- 偏离：4000 样本数据扩展点未做（15:45 UTC 用户改用 V4 数据后取消）；改为训练 V3 train 0–999 作为 V4/V5 对照（见 docs/v4/PRIOR_CHECK_ZH.md）。

- 交接：docs/v3p/HANDOFF.json: main_run v3main_C_seed29 (2000-sample prior) + 9-run B/C/D ensemble (docs/v3p/ENSEMBLE_BCD9_{VAL,TEST}.json, runs/v3main_ens_bcd9_{val,test}).
