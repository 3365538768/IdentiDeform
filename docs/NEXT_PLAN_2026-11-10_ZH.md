# R 线第二轮分析与下一步计划（2026-11-10）

资源：从本日起只使用 A800-2 的 GPU 4–7（GPU 0–3 归其他实验，队列 `scripts/r_queue.py` 已硬限制）。test 集仍未读取。

## 1. 已完成实验的结论

指标：验证 MAE（训练集标准化，越低越好），3 seeds 均值±sd；“族内 r”为同一本构族内 Pearson r（3 族平均）；R1b/R3/R4 使用可辨识目标（E/ρ、ν、ρ、σ_y/ρ）。

| 实验 | 组 | MAE | 族准确率 | 族内 r(E/ρ) jelly / plasticine | 族内 r(σ_y/ρ) metal |
|---|---|---:|---:|---|---:|
| R1b DINOv3 16帧 | C | 0.686 ± 0.021 | 0.64 | 0.22 / 0.25 | 0.40 |
| R3 DINOv3 64帧 | C64 | 0.682 ± 0.016 | 0.63 | 0.24 / 0.29 | 0.38 |
| **R4 V-JEPA 2 ViT-L 冻结** | **Cvj** | **0.581 ± 0.007** | **0.78** | **0.42 / 0.44** | **0.54** |
| R4 | Bvj（无场） | 0.598 ± 0.030 | 0.76 | | |
| R4 | Dvj（反馈） | 0.584 ± 0.019 | 0.77 | | |

1. **视频骨干是目前最大的杠杆**：同头、同预算下 V-JEPA 2 比 DINOv3 误差低 15%，3 个 seed 的物体配对 bootstrap 区间全部不跨 0（[−0.18,−0.06]、[−0.13,−0.05]、[−0.23,−0.09]）。族分类 0.64→0.78，族内 E/ρ 相关约翻倍。
2. **帧数不是原因**：R3（DINOv3 64 帧）与 16 帧无差别；R2b 也显示 16 帧与 64 帧的像素差几乎相同。V-JEPA 的收益来自时空联合表征，而非多看帧。
3. **场辅助监督小而一致**：C 相对 B 在 DINO-R1 +2.75%、R1b +1.83%、V-JEPA +2.66%，方向在 3 个实验中一致，但单个实验区间多跨 0。**场反馈（D）在 4 个实验中都没有收益**（−1.24%、−0.33%、−0.48%）。
4. **VLM 零样本失败**：Qwen3-VL-8B（3 视角×8 帧，协议见 `runs/r5_vlm_qwen3vl8b_val/protocol.json`）399/399 可解析，但 96% 预测为 jelly，族准确率 0.30（低于随机 0.33），标准化 MAE 2.96（常数基线约 0.85）。
5. **R2b 物理可分辨性**：每半个数量级的 E/ρ 变化在 224px 下造成的形变差，jelly 在 press 下 1–12px、drop 下 0.3–8px，随区间强烈变化；plasticine σ_y/ρ ≥1e4 时差异为 0（不屈服，标签不可观测，应作删失处理）；jelly 刚性端 drop 振荡 9–15Hz，高于 16fps 的奈奎斯特频率。metal-E 扫描在高 E/ρ 处 CUDA 失败（疑似 CFL），R2 已显示 metal E×4 只改变 1% 运动。

## 2. 对 rebuttal 的含义

- a1nG：全局散点线性主要来自族间差；族内信息受物理可辨识性限制（ρ 不可辨识、metal E 不可见、plasticine 高屈服删失）。换视频骨干后族内相关显著上升——可以展示“模型确实学到材料”的证据，同时诚实说明可辨识边界。
- AKYF/Nxg5：严格的“只去反馈”消融已完成，结论是反馈无收益，辅助场监督有小幅一致收益；论文表述需改为“场监督 + 视频表征”，删除反馈是主要贡献的说法。
- Nxg5 VLM：给出完整可复现协议与零样本结果；静态外观方法在本基准按构造只能达到族均值（标签与外观独立，物体对 log E 的 R²≈0.02），P1b 首帧对照直接量化这一点。
