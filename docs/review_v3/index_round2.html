IdentiDeform V3 contact review (round 2)

Each clip stacks the variants as rows (three camera views each); the row name is printed in the video. Same objects and random draws in every row. Object screening page · round 1

  • Gravity: 0 for every action except drop. Drop keeps g = 9.8 with the floor 0.12 below the object (was 0.25).
  • Contact only: press plate starts above the object; bend uses a fixed support plus two pushers; shear and stretch use two parallel-jaw grippers that close on the object's two ends (0–0.5 s), hold (to 0.75 s), then move (shear: opposite directions across the long axis; stretch: apart along it) and open at 3 s. Gripper size and closing depth follow each end's local cross-section. The floor touches each object's own lowest point.
  • Press variants (press and press–hold–release): sticky floor with g = 0; slip floor with gravity switched on when the plate lifts; slip floor with constant g = 2. The final row uses the sticky floor.
  • V3 ranges (final row): log10E/ρ jelly 3.5–6, plasticine 3.5–5.5, metal 4.5–6; log10σy/ρ plasticine 1.5–4.5, metal 2.5–4.5. The caption shows old → new value for the same random draw.
  • Stray particles outside the grid are moved inside before simulating; this removed the crashes on metal samples (0 failures in the final row).
Open points: (1) which press variant? With the sticky floor a few long or flat objects (telescope #15, tray #18) still lift off after release because they touch the floor at only a few points; gravity after release keeps them down. (2) Gripper motions are modest (shear 25% of depth per end, stretch 15% of length per end); larger is possible. (3) Force-controlled actions are planned as a separate subset after the main run.
