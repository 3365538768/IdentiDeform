# V2 论文 3 天冲刺计划（2026-11-13 起）

定位：可辨识物理参数基准 + "前馈预测 + 仿真闭环修正"方法 + 跨引擎 few-shot。所有实验基于已有 V2 数据（2000 train / 300 val）+ 新增 300 test，规模小但有对照、有 3 seeds、有物体级 bootstrap。

## 新贡献（按优先级）
1. **C1 仿真闭环修正（analysis-by-synthesis）**：V-JEPA 头给出初值 → 在同一引擎里用观测动作重放，CMA-ES 小预算（≤12 次仿真）优化 E/ρ、σ_y/ρ 的掩码 IoU。复用 replay 管线。预期显著提升族内精度，同时给出"预算-精度曲线"（0/4/12 次仿真）。
2. **C2 软族混合头**：族分类是最大误差源（族准确率 ~0.7，已知族上限 MAE 0.535）。用族后验加权的 mixture 回归（替代失败过的硬分层头），只训头、走缓存，几小时。
3. **C3 多 seed / 多动作集成 + 不确定度**：零成本，报告校准覆盖率。
场监督（C 组）作为辅助项如实报告，不作主卖点。

## few-shot 与多引擎（验证性，小规模）
- **跨引擎**：libuipc（已标定，`.engine-envs/uipc`）生成 ~150 条 press 样本（简单几何、相同相机/动作协议），MPM 训练的模型冻结骨干，K=0/8/32 个物体适配头，比较响应误差与可辨识量 MAE；对照：uipc 全监督（剩余物体）。
- **外部数据**：PAC-NeRF 4 个有 GT 的命名场景（torus/bird/playdoh/cat）留一评估，K=0 vs 用其余 3 个场景适配；只作定性 + 数值表，不用 oracle/masiv。
