## 结论

1. **视频骨干的提升在 test 上完全复现**：V-JEPA 2 比 DINOv3 误差低 15%，与验证集一致，3 个 seed 区间都不跨 0。可作为 rebuttal 的主改进。
2. **只看外观等于常数**：首帧静态 0.815 ≈ 常数 0.835，族分类为随机水平。本基准按构造需要动态证据；静态方法（PIXIE/VoMP 类）在此只能到常数水平，应在回复中说明，而不是当作“我们打败了它们”。
3. **场反馈：test 与 val 方向不一致**。val 上 D 比 C 差 0.3–1.2%，test 上 DINO 的 D 比 C 好 2.9%、V-JEPA 好 0.5%，但所有区间都跨 0。诚实结论是“反馈的收益在统计上不可分辨”，不能作为主要贡献，也不能说完全有害。
4. **场辅助监督**同样是小幅、区间跨 0 的改善（1.8–2.6%），5 组实验方向一致。
5. **零样本 VLM 远差于常数**（MAE 3.1），几乎全部判成 jelly。
6. **剩余差距主要在本构族分类**：已知 GT 族的特权参照（0.535）仍优于最好模型（0.613）；V-JEPA 族准确率 val 0.77 → test 0.69，存在泛化差。下一步提升优先放在族分类和 Data V2 上。
7. 族内指标在 test 上与 val 一致：σ_y/ρ（metal）r≈0.64，E 族内 r≈0.1；ρ 的族内 r≈0.4 来自标签采样先验（见 `P1_RESULTS_2026-11-10_ZH.md` 第 3 节），不能当作密度辨识证据。
