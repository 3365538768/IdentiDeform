# 下一步实验规划（2026-11-09，A800-2）

依据：review1.txt 三位审稿意见、Codex_README.md 交接结论、docs/ 下 M1/M2/G1F/NF/G2/G3 结果，以及本次新增审计 `docs/WITHIN_LAW_AUDIT.json`（`scripts/audit_within_law.py`）。

## 0. 新诊断：当前材参能力几乎全部来自本构族分类

对已有最佳验证预测（128 条/10 物体，seed17）按本构族拆分：

| 运行 | 本构族准确率 | E MAE | 已知族→族均值 MAE | E 族内 r（族0/1/2） | ρ 预测/真值 std 比 |
|---|---:|---:|---:|---|---:|
| m2v2_B RGB | 0.625 | 0.627 | **0.272** | −0.00 / +0.05 / +0.19 | 0.07–0.20 |
| m2v2_C 辅助 | 0.680 | 0.590 | 0.272 | +0.21 / +0.10 / +0.32 | 0.16–0.23 |
| m2v2_D 场桥 | 0.672 | 0.555 | 0.272 | +0.23 / +0.01 / +0.31 | 0.10–0.23 |
| g1f_O 真场 oracle | 0.625 | 0.564 | 0.272 | −0.07 / +0.17 / −0.02 | 0.06–0.40 |

（族均值参照使用 GT 族和验证集统计，只是诊断参照，不是可部署 baseline。）

结论：

1. 全局 E–GT r≈0.6–0.7 主要由族间均值差（log E 族均值 8.8 / 14.4 / 10.9）贡献；**族内 E、ν 几乎与 GT 无关**，ρ 基本输出常数。这正是 a1nG 说的“GT 与预测接近独立”。
2. 即使给真场（O），族内仍不相关 → 瓶颈不在桥结构，而在**可辨识性 + 数据激励**。
3. 物理原因：79% 样本为速度驱动边界、无力记录。均质线弹性在位移控制、准静态下形变场与 E 无关（只与 ν、几何有关）；E 只能通过惯性/重力以 E/(ρgL)、波速 √(E/ρ) 相对加载时间尺度进入，ρ 单独不可辨识。材参与外观独立采样（物体对 log E 的 R²≈0.02），因此静态外观方法在本基准上按构造只能到族均值水平。
4. 最大单项杠杆是本构族分类（62–68%）：若族判对，E MAE 上限可降到 ~0.27 量级。

所以“换更大骨干/更复杂桥”不是优先项。规划分两条线：**R 线**（11-14 封版前完成 rebuttal 证据）与 **V2 线**（重新定义目标、数据和模型，真正提升能力并支持多引擎和横向比较）。

**R1 全量数据重训（11-10～11-12，GPU 0–5）**

- 层级输出头 H：本构族分类 → 族条件回归（mixture / 每族独立头），损失和指标都按族归一化。这对所有组同等启用，不只给 D。
- 严格 C/D（Codex §7.2 定义）：保留 bottleneck、场预测、场 GT 监督、阶段与预算，只去掉预测场→材参反馈；外加 B（无场）。seeds 17/29/43，3×3=9 个运行，各约 1/3 卡即可并行。

**R2 可辨识性受控实验（11-10～11-12，GPU 6–7）** — a1nG + AKYF
- 用原 Warp-MPM 求解器、固定 3–5 个几何：只变 E（ρ、ν、动作固定），以及固定 E/ρ 变尺度，验证“位移驱动下形变与 E 无关、E/ρ 才可辨识”。产物：响应差异–参数曲线，直接解释散点独立。
- 原 MPM 物理校验：自由落体加速度、dt/网格收敛、阻尼按物理衰减率换算、drop 回弹扫描与 Spring-Gaus 对照；报告可靠参数区间，不为凑 60% 回弹调参。

**R3 小规模“可辨识数据”证据（11-12～11-13）**

**R4 baseline 与可复现性（11-11～11-13）** — AKYF / Nxg5

## 3. V2 线：真正提升能力

### 3.1 目标重定义：预测“可辨识量 + 后验”，而不是点估计 E/ρ
- 输出：本构族；族内可辨识组 ν、log(E/ρ)（波速/重力下垂）、log(σ_y/E)（屈服应变）、阻尼率；只有输入轨道提供尺度/力/质量时才输出绝对 E、ρ。
- 概率输出（mixture density / flow），校准 95% 覆盖，允许多解。
- 主终点改为**未见动作响应**：从动作 A 的视频预测参数，在引擎里重放动作 B，比较轨迹/轮廓误差。这与参数单位无关，天然适合多引擎和与在线优化方法比较。

### 3.2 Data V2：设计成可辨识的数据（GPU 6–7 先 pilot 测吞吐）
- 动作脚本 = 加载 → 保持 → 释放（自由振荡/回弹）；drop 记录初始高度；一部分为力控压头并记录力；全部记录公制尺度与相机内外参。
- 匹配设计：同几何/动作/相机下单参数扫描组，支撑族内排序损失和族内评估。
- 外观–材料相关子集（语义一致采样，给 PIXIE/VoMP/VLM 公平机会）与反语义子集（同外观不同物性），检验静态先验与动态证据的互补。
- 渲染 448–512，非 224；阻尼用物理衰减率，dt/网格收敛通过后才准入。
- 规模：先 1k 条 pilot（测每条仿真+渲染 GPU 时），再按吞吐决定 5k–20k。

### 3.3 多引擎
- 同一场景/动作协议在 ≥3 个引擎生成：原 Warp-MPM、Genesis（MPM/FEM，CUDA12 可用）、libuipc（已标定）；Newton 在隔离环境验证驱动 535 兼容后再加。
- 架构：共享视频编码器 → 共享“响应嵌入”（以统一探针动作的预测响应为辅助目标）→ 每个 engine/version/law 独立参数头。
- 评估：留一引擎 K-shot（K=0/8/32 个独立物体实验）适配；跨引擎只比响应，不比同名 E 数值。

### 3.4 模型结构
- 骨干：从“冻结逐帧 DINO + 4×4 单元注意力”换成视频基础模型（V-JEPA 2 ViT-L/g 或 VideoMAE-v2），末端若干块小学习率微调；保留 DINOv3 作为外观/族分类分支。
- 拉格朗日运动证据替代欧拉 2D 场桥：CoTracker3/TAPNext 点轨迹 → 去刚体（逐帧 Procrustes）→ 局部应变代理、释放段频谱（主频、衰减）→ 轨迹 transformer。先在渲染对应真值上验收教师。
- “场桥”改为证据 token：预测的轨迹/应变/接触 token 与 RGB token 共同进入头；用 C/D/G 控制严格隔离其收益。
- 训练期物理教师：可微 MPM 在训练集上逐场景拟合得到教师后验，做蒸馏（参照 Analytic Dynamics 的已知结果，作为对照而不是新意本身）。
- 可选 M5：前向预测 + 少步可微仿真修正（10/30/120 s 预算曲线）。

## 4. 决策门

| 节点 | 通过 | 不通过 |
|---|---|---|
| R1 全量 C/D | D 稳定优于 C ≥2% | 报告反馈无收益，rebuttal 主张辅助监督 + 层级可辨识目标，V2 不再投入 dense 反馈 |
