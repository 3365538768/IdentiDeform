# P4d 配对 V2 试点结果与下一步计划（2026-11-11）

原始数据：`docs/p4d/P4D_RESULTS.json`、`docs/p4d/P4D_TAP_SIGNAL.json`。只用验证集，test 未读取。

## 1. 设计

两臂物体、动作（press / tap）、参数、视角完全相同，只差阻尼：low（rpic 0、grid 0.99999/子步，各族相同）vs V1（各族原值）。参数按可辨识量采样（E/ρ、σ_y/ρ 对数均匀，ρ 独立）。两臂都成功的样本 472 train / 112 val（10 个验证物体）。V-JEPA 2 ViT-L 冻结特征 + C 头，3 seeds，目标为 E/ρ、ν、ρ、σ_y/ρ。

## 2. 结果

| 指标 | V1 阻尼 | 低阻尼 |
|---|---:|---:|
| 验证 MAE（可辨识目标） | 0.855 ± 0.008 | **0.801 ± 0.008** |
| 相对改善 / 物体配对区间 | | **+6.3%，3/3 seed 不跨 0** |
| 族准确率 | 0.48 | 0.57 |
| 族内 r(E/ρ) jelly / metal / plasticine | 0.12 / 0.18 / 0.21 | **0.24 / 0.34 / 0.32** |
| 族内 r(σ_y/ρ) metal / plasticine | 0.26 / −0.18 | **0.60 / 0.65** |
| 族内 r(ρ)（应≈0，对照） | 0.02 / −0.16 / −0.21 | 0.02 / 0.09 / −0.09 |

按动作拆分（低阻尼）：press 下 E/ρ 族内 r 为 0.55 / 0.40 / 0.48；tap 下 jelly、plasticine ≈ 0。

## 3. 结论

1. **阻尼是可辨识性的主要可控因素**。只改阻尼，误差降 6.3%（过 2% 门槛，区间不跨 0），σ_y/ρ 族内相关从 0.26 / −0.18 升到 0.60 / 0.65，E/ρ 约翻倍。V1 的强阻尼（每子步施加）是 V1 族内参数难学的数据侧原因之一。
2. **ρ 不可辨识被干净地证实**：ρ 与 E/ρ 独立采样后，族内 r(ρ) 在两臂都≈0。V1 中 0.4–0.6 的 ρ 相关来自标签采样先验，这一点可直接写进 rebuttal。
3. **tap（压 10% 后释放）在真实物体上无效**：不经学习、直接从物体掩码提取释放后的振荡频率/幅度，与 E/ρ 的族内 Spearman 也只有 |ρ| ≤ 0.35 且方向不一致。立方体扫描中的清晰振荡在真实形状上幅度太小（多数物体只占约 40×40 像素），且无重力时会反弹漂移。增益几乎全部来自 press 和屈服相关信息。
4. 局限：试点只有 472 个训练样本，绝对 MAE 不能与 V1（4021 个）的数值直接比较；每族每动作的验证样本约 19 个，按动作拆分的相关系数误差较大（±0.2）。
