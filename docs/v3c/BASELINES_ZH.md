# V2 main 验证集对比基线（V3c）

由 `scripts/v3c/write_zh.py` 从 `docs/v3c/BASELINES_VAL.json` 自动生成。验证集 283 个样本、10 个物体，test 未使用。

## 协议
- 目标空间：specific（E/ρ、ν、ρ、σY/ρ；ln1p 后用训练集统计量标准化）。标准化 MAE 对所有计分的（样本，参数）项取平均。可辨识量为 E/ρ 和 σY/ρ；ρ 是预期不可辨识的对照量。
- 训练出的方法：每个 run 取验证集 MAE 最好的 epoch（与 V2 main 报告的规则相同），对所有训练方法同样偏乐观。DINOv3 与 V-JEPA 的头部、预算、早停、划分都一致，差别只在骨干和帧数（DINOv3 16 帧，V-JEPA 32 步）。
- 物体 bootstrap：成对比较“方法 − V-JEPA C”的物体宏平均 MAE 差（2000 次重采样）；负值表示 V-JEPA C 更好。训练出的方法按同种子配对；确定性基线分别与 C 的 3 个种子配对。只有 10 个物体，置信区间偏宽。

## 说明
- VLM：可解析回答 283/283。但绝大多数回答只是照抄提示里给的参数范围下界（E=36 Pa, ν=0.1, ρ=300, 判为 jelly），与 R5 在 V1 上的现象一致（R5 为 347/399 条抄下界）。因此 VLM 比常数基线还差，这一点照实报告。提示词与 R5 相比只改了参数范围那一句（换成 V2 训练集范围）。
- 律类均值（特权）使用 GT 律类，不能部署，只作为“只知道律类时能做到多好”的参照；律内 r 无定义。
- 首帧静态基线：只看首帧外观（P1b 协议），检验外观本身能否泄漏材料信息。

## 结论
- 视频骨干方面：DINOv3 ViT-L 16 帧（B 0.661±0.005，C 0.663±0.002）比 V-JEPA 2 C（0.644±0.009）略差，物体平均差约 −0.017。成对物体 bootstrap 的 3 个种子中只有 1 个种子 CI 不含 0，所以只能说“V-JEPA 略好，证据弱”。DINOv3 的 σY/ρ 律内 r 略高（0.89 对 0.875），E/ρ 律内 r 偏低（0.56–0.58 对 0.63）。
- 运动信息是必要的：首帧静态 DINOv3（0.857）与常数基线（0.858）没有区别，律类准确率在 1/3 左右（随机水平），律内 r 约等于 0。仅凭外观无法推断材料，这一点支持“基准不存在外观泄漏”的论点。
- 特权律类均值（0.786）明显差于所有视频模型（3 个种子的 CI 均为负，差约 −0.14）。也就是说，视频模型除了识别律类，还恢复了律类内部的参数信息。
- Qwen3-VL-8B 零样本（1.601）比常数基线还差：几乎所有回答都照抄范围下界，与 V1/R5 的结果一致。
- 局限：验证集只有 10 个物体，CI 偏宽；验证集同时也是 epoch 选择所用的划分，训练方法的数字偏乐观；test 尚未使用，按 `docs/v3c/TEST_PROTOCOL.json`（已冻结）只评估一次。
