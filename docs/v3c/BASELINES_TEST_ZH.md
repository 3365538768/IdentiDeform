## 结论（test 与 val 对照）
- 排序与 val 一致：V-JEPA 2 集成 > V-JEPA 2 单模型（B/C/D）> DINOv3 16 帧 > 特权律类均值 > 首帧静态 ≈ 常数 > Qwen3-VL 零样本。
- 训练方法的 test MAE 普遍比 val 高约 0.02–0.03（V-JEPA C 0.644→0.676，DINOv3 0.66→0.69）。常数基线 val/test 几乎相同（0.858/0.853），说明 test 物体并不更难；差距主要来自 val 上选 epoch 的乐观偏差和对新物体的泛化差。test 上的律类准确率反而高于 val（0.72–0.75 对 0.66–0.69）。
- V-JEPA 对 DINOv3：test 上 DINOv3 B/C 比 V-JEPA C 差约 0.010–0.011，3 对 CI 中最多 1 对排除 0，证据弱，与 val 结论相同。DINOv3 的 σY/ρ 律内 r 更高（0.81–0.83 对 0.75–0.77），E/ρ 更低（0.54–0.56 对 0.59–0.61）。
- B/C/D 之间：test 上 B、D（0.667）略好于 C（0.676），但 CI 基本含 0，场预测桥接 C 在 test 上没有优于 B。
- 集成：9 run B/C/D 等权集成 test MAE 0.646，相对单个 C 在 3 个种子配对中 CI 都为正（+0.031），是 test 上最好的方法；C 3 种子集成为 +0.018（2/3 显著）。集成规则预先固定，没有在 test 上选择。
- 首帧静态 ≈ 常数（0.852 对 0.853，律类准确率在随机水平）：仅凭外观无法推断材料，test 上再次确认。特权律类均值（0.792）明显差于所有视频模型（3/3 显著）。
- Qwen3-VL-8B 零样本（1.580）依旧比常数差，回答模式与 val 相同（照抄范围下界）。
- 局限：test 只有 10 个物体，物体 bootstrap 的 CI 较宽；集成成员的 epoch 仍是在 val 上选的。
