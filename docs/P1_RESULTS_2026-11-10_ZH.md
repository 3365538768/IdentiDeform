# P1 / P1c 结果分析（2026-11-10，GPU 4–7）

验证集 399 条 / 10 物体，3 seeds（17/29/43），test 未读取。原始数据：`docs/p1/P1_RESULTS.json`、`docs/p1c/P1C_RESULTS.json`。P1c 的 B seed29 在分析时仍在第 25/30 轮，按当时最佳计入（0.588）。

## 1. 原论文参数空间（E/ν/ρ/σ_y）下的主对比

| 模型 | 验证 MAE | 族准确率 | 说明 |
|---|---:|---:|---|
| 首帧静态（DINOv3，只看第 1 帧） | 0.831 ± 0.001 | 0.33（=随机） | 族内 r 全部≈0 |
| DINOv3 C（R1） | 0.677 ± 0.010 | 0.66 | |
| V-JEPA 2 ViT-L B | 0.581 ± 0.012 | 0.77 | |
| **V-JEPA 2 ViT-L C（场监督）** | **0.576 ± 0.009** | **0.77** | |
| V-JEPA 2 ViT-L D（场反馈） | 0.577 ± 0.015 | 0.79 | |

- **V-JEPA C vs DINOv3 C：误差降低 12.1% / 16.1% / 16.6%**，3 个 seed 的物体配对 95% 区间均不跨 0（[−0.14,−0.01]、[−0.17,−0.07]、[−0.16,−0.09]）。在原口径下同样成立，可作为 rebuttal 主结果。
- **动态是必要的**：首帧静态模型族分类等于随机，误差比 V-JEPA 高 30%（3 seed 区间全不跨 0）。标签与外观独立采样，任何静态/首帧方法（PIXIE、VoMP 类）在本基准上按构造只能到常数水平——这既是基准“要求动态证据”的证据，也必须如实说明。
- **场监督 / 反馈**：V-JEPA 下 C 比 B 好 0.83%（区间跨 0），D 比 C 差 0.28%。结合前 4 组实验：辅助场监督收益小（0.8–2.8%），反馈始终无收益。

## 2. 骨干规模（P1c，可辨识目标）

| 骨干 | B | C |
|---|---:|---:|
| V-JEPA 2 ViT-L（300M） | 0.598 ± 0.030 | **0.581 ± 0.007** |
| V-JEPA 2 ViT-g（1B） | 0.590（2 个完成 seed + 1 个进行中） | 0.618 ± 0.012 |

ViT-g 没有超过 ViT-L，C 组反而差 6%。按决策门（改善 <2%）**停止扩大冻结骨干**。可能原因：ViT-g 特征维度 1408 而投影头容量相同、未调学习率；但不值得继续投入。

## 3. 一个必须披露的标签先验效应

V-JEPA 原口径下，jelly / plasticine 的**族内 ρ 相关达到 0.51–0.64**，看起来像学到了密度，但 R2 已证明 ρ 在这个仿真器里不可观测。原因是数据集的采样方式：jelly 的 E 范围窄、ρ 范围宽，训练标签中 ln ρ 与可见量 ln(E/ρ) 的相关为 −0.84（plasticine −0.73，metal −0.24）。模型看到 E/ρ，再借助标签先验“猜”出 ρ。

因此：
- 不能把 ρ 的相关当作“从视频辨识密度”的证据；
- 同理，jelly 的原口径 E 相关受 E/ρ 中 ρ 成分主导，族内 r(E) 只有 0.14–0.19；
- rebuttal 中族内指标应以可辨识量（E/ρ、σ_y/ρ）为主，原口径 E/ρ 分项只作补充并附此说明。

## 4. 汇总结论

1. 当前最强系统：**V-JEPA 2 ViT-L 冻结视频特征 + 场辅助监督（C）**。相对论文同类结构（DINO + 场）误差降低约 15%，族分类 0.66→0.77，可辨识量的族内相关约翻倍（E/ρ 0.2→0.4，σ_y/ρ 0.4→0.55）。
2. 原论文“预测场反馈”机制在 5 组严格对照中都没有收益，应从主要贡献中撤下，改为“场监督作为辅助”。
3. 剩余误差的主要来源是可辨识性边界（ρ 不可见、metal E 不可见、plasticine 高屈服删失、刚性 jelly 振荡超过 16fps），这些需要 Data V2 解决，而不是更大的冻结骨干或更多帧。

## 5. 下一步建议
