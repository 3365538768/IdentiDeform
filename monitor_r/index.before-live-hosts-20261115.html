任务说明
阶段 / 组名含义
V2mainV2 主实验（低阻尼 + 重力 + 6 种动作，1955 训练 / 283 验证）：冻结 V-JEPA2 特征 + B/C/D 三种头，每种 3 个 seed。它就是"材质先验"本体。
B / C / DB：只用视频；C：加物理场辅助监督；D：再把预测场反馈给参数头（原文的场桥）。目前三者区分不出来，场桥降为消融。
v3V2 独立 test 集（300 条，物体不与训练和验证重叠），只在最后评估一次。
v3a跨引擎 K-shot：libuipc（FEM）样本生成与适配，比较 K=0/4/8/16/32/全量，以及引擎 token 联合训练。
v3b-C1主贡献：先验 + 仿真闭环修正。从模型先验或无信息初值出发，在引擎里重放观测到的动作，用 CMA-ES 修正参数；比较精度对仿真次数，得出加速比。每个任务是一次仿真。
v3b-C2软族混合头：按族后验加权各族回归，减少"族判错就整体出错"。
V3c横向基线：DINOv3 B/C（≈原文结构）、首帧静态（S）、Qwen3-VL 零样本、常数/族均值；PAC-NeRF 4 场景外部 few-shot。
v3dC1 test 复现：在 30 个 test 样本上用与 val 完全相同的代码比较先验+修正与无信息仿真拟合，回应"主结论只在 val 上"的质疑。
v3e夹爪数字孪生任务：用不同来源的参数（真实/先验+修正/只用先验/无信息拟合/族均值/固定启发式）在孪生中规划夹紧深度，再用真实参数执行一次，统计成功率与最优深度差。
v3fSpring-Gaus 与 PIXIE：在 Spring-Gaus 数据上测试我们的模型（排序、少样本校准、真实视频定性重放）；运行 PIXIE 官方代码作为已发表的静态外观基线。
v3g官方逐场景方法对齐：运行 PAC-NeRF、Spring-Gaus、PhysTwin 官方实现，记录每个场景的耗时与误差，与我们的前馈先验（以及先验初始化 PAC-NeRF）对比。
表中各列验证 MAE：标准化参数误差，越低越好。族准确率：本构族分类准确率。族内 r：同族内预测与真值的相关。
