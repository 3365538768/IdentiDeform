任务说明（当前与后续实验）

目标：从固定 3 视角视频推断物体材料参数（本构族 jelly / metal / plasticine，以及 E/ρ、ν、ρ、σ_y/ρ）。只用验证集选模型，test 只在协议冻结后评估一次。表格里的“阶段”下拉框可按下面的阶段名筛选。

阶段 / 组名含义
V2main 进行中V2 主实验。新数据：低阻尼、开重力、6 种动作，约 2000 条训练 + 300 条验证。流程：v2main-gen 仿真并渲染样本 → v2main-prep 建样本清单（训练样本少于 1000 条就不训练）→ v2main-cache 提取冻结的 V-JEPA2 ViT-L 视频特征 → B/C/D-v2main 训练 → report 汇总、做物体级 bootstrap 对比。
B / C / D同一骨干和训练预算下的三种模型。B：只用视频预测参数，不用物理场。C：额外让模型预测物理场（接触、流动、应力）作辅助监督。D：在 C 基础上把预测的场反馈给参数头（原论文的 field bridge）。比较 C 与 B 看场监督有没有用，D 与 C 看场反馈有没有用。
seed 17 / 29 / 43每组跑 3 个随机种子，汇总表显示均值 ± 标准差。只有 ≥2/3 个种子的物体级置信区间都不跨 0，才算显著改进。
v3（v3-gen） 进行中生成 V2 的独立 test 集（300 条，物体与训练和验证都不重叠）。只用于最后一次性评估。
v3a 进行中多引擎 few-shot。用第二个物理引擎 libuipc（FEM）生成约 160 条弹性样本（v3a-gen / v3a-data）。把在 MPM 数据上训练的模型迁移过去，比较不适配（K=0）、只用 8 或 32 个 uipc 样本适配，以及 uipc 全量训练（v3a-fewshot），看模型能否快速适配新引擎。
v3b-C2 进行中新方法：软族混合头。现在最大的误差来源是本构族判错。模型改为先给出每个族的概率，再按概率加权各族的回归结果，判错族时不会整体崩掉。只训练输出头，用缓存特征训练很快。
v3b-C1 后续新方法：仿真闭环修正。用模型预测的参数作初值，在同一引擎里重新仿真观测到的动作，再按与观测视频的掩码 IoU 微调 E/ρ、σ_y/ρ。仿真预算分别是 0、4、12 次，在约 60 个验证样本上测“预算换精度”的曲线。每个任务就是一次仿真。
V3c 进行中横向对比基线（与 V-JEPA 模型用同样的数据划分）。v3c-dino-cache：提取 DINOv3 逐帧特征。v3c-dino-B / C：DINOv3 骨干的 B、C 模型（对应原论文结构）。v3c-dino-S：首帧静态对照，只看第一帧外观。v3c-vlm：Qwen3-VL-8B 零样本（3 视角 × 8 帧，直接问参数）。另外还有常数和族均值两个参照。
v3c-pacnerf 进行中外部数据 few-shot。PAC-NeRF 公开数据里 4 个有真实参数的场景（torus、bird、playdoh、cat），做直接迁移和留一场景适配。规模小，只作验证性证据。
Day1 后续replay：把预测参数放进仿真，换成没见过的动作重放，对比真实参数和族均值参数的结果。report：生成 Day-1 汇总（F1 学习曲线、P4d、replay、V2main），等 V2main 报告完成后自动运行。
其余阶段R1–R5、P1–P4d、F1、B1、Quality-V2 等是 11-09 到 11-12 已完成的实验，结论见 docs/*_ZH.md。它们的缓存和权重已经清理，只保留结果文件。
表中各列验证 MAE：训练集标准化后的参数平均误差，越低越好。族准确率：本构族分类准确率。族内 r：同一本构族内预测与真值的相关系数，看模型是否真的读出了族内的连续参数，而不只是分对了族。场预热 / 联合训练：C 和 D 先单独训练场预测，再和参数一起训练。
